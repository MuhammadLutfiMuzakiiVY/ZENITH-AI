# 🌌 Zenith AI: Intelligence Co-pilot

**Zenith AI** is a premium, high-performance AI chatbot designed for developers and power users. Built focusing on **AI Productivity and AI API Integration**, Zenith provides a futuristic workspace for brainstorming, deep research, and focused execution.

---

## ✨ Project Highlights

- **Modern Glassmorphic UI**: A state-of-the-art interface built with React, CSS3, and Framer Motion.
- **Dynamic Context Modes**:
  - 🎨 **Creative Mode**: Non-linear brainstorming and creative synthesis.
  - ⚡ **Focus Mode**: Concise, objective-driven responses with productivity integrations.
  - 🌐 **Research Mode**: Deep analysis and semantic synthesis of complex topics.
- **Contextual Memory**: Remembers last interactions within the session to maintain conversation flow.
- **Vibrant Aesthetics**: Custom HSL color palettes, neon accents, and smooth micro-animations.

## 🛠️ Tech Stack

- **Frontend**: React.js (Vite)
- **Styling**: Vanilla CSS3 (Custom Design System)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Model Integration**: Simulated neural-link logic (Extensible to OpenAI/Gemini API)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone [YOUR_GITHUB_URL]
   cd Zenith-AI
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
